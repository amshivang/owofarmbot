# OwO Auto Bot (Desktop)

A highly optimized, elegant desktop automation console for OwO on Discord.

## Features
- **Intelligent Farm Loop:** Automatically runs `owo h` and `owo b` commands. Smartly equips hunting gems from your inventory to maximize yields and automate setup.
- **Real-time Websocket Logs:** Streams bot events and Discord channel logs directly to your dashboard in real-time, featuring smooth, jump-free auto-scrolling.
- **Integrated Gambling:** Play coinflip (`cf`) and slots (`s`) automatically with custom base amounts integrated alongside your primary farm cycles.
- **Pray or Curse:** Run pray or curse commands targeting yourself or others to maintain active multipliers, with customizable repetition limits.

## Installation & Usage
1. Download the latest `OwO Auto Bot.exe` from the [Releases](../../releases) tab.
2. Run the executable.
3. Extract your Discord User Token via your browser (F12 Developer Tools -> Network tab -> `Authorization` header).
4. Paste it into the dashboard and click **Start Farming**!

> **Warning:** Self-botting is against Discord's Terms of Service. Use this at your own risk. The developers are not responsible for any account bans.
